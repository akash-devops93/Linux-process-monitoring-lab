# Linux-process-monitoring-lab
Hands-on Linux Process Monitoring Lab covering process identification, monitoring, resource usage analysis, and basic system administration commands using RHEL Linux.
## Commands Practiced

- ps
- ps -ef
- ps aux
- top
- pgrep
- pidof
- pstree
- jobs
- bg
- fg
- free -h
- uptime
- w

## Tasks Completed

### Task 1
View running processes using ps.

### Task 2
Identify process IDs using pgrep and pidof.

### Task 3
Monitor live system activity using top.

### Task 4
Display process hierarchy using pstree.

### Task 5
Check memory usage using free -h.

### Task 6
Check system uptime and logged-in users.

### Task 7
Work with background and foreground jobs.

## Learning Outcomes

- Understand Linux process lifecycle.
- Monitor running processes.
- Identify process IDs.
- Analyze CPU and memory usage.
- Manage foreground and background jobs.
- Perform basic system monitoring.

## Environment

- RHEL Linux
- VMware Workstation
